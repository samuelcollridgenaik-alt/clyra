# Clyra branding

Original generated mark: indigo conversation-shaped C with a teal resolution check. The same asset appears in web navigation/sign-in/favicon, Flutter sign-in and Android launcher density variants. Existing Clyra text branding and UI colors remain intact.

- Master raster: `mobile/assets/branding/clyra-mark.png`
- Web: `web/public/clyra-mark.png`
- Android: `mobile/android/app/src/main/res/mipmap-*/ic_launcher.png`

Created with the built-in image-generation tool, not copied from a stock logo. It is a raster asset, not a trademark clearance or exclusivity claim. Packaging derivatives were resized without redrawing the mark; original alpha is preserved.

## Generation prompt

Use case: logo-brand. Asset type: square app icon for Clyra, a campus grievance and facilities app. Create an original premium geometric C monogram that subtly combines an open conversation loop and a small resolution/check accent. Existing product palette is deep navy, indigo and teal: use a deep navy solid square background, luminous indigo C and restrained bright teal accent. Flat clean vector-like artwork, bold silhouette, balanced negative space, crisp edges. Center a single mark within the middle 65 percent so it survives Android circular masks and reads well at 32 pixels. Square 1024x1024 icon, edge-to-edge background, no outside margins, no mockup, no separate rounded tile, no letters or words beyond the C-shaped symbol, no gradients or shadows, no stock logos or watermark.

The returned image has transparency; that alpha channel is retained in project assets.
